# De Gênesis a Apocalipse — Estudo Bíblico

Aplicativo web estático preparado para publicação no GitHub + Vercel.

## Arquivos
- `index.html` — aplicativo completo
- `vercel.json` — configuração simples para publicação na Vercel

## Publicar na Vercel
1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para o repositório.
3. Na Vercel, escolha **Add New > Project**.
4. Importe o repositório do GitHub.
5. Mantenha as configurações padrão de projeto estático.
6. Clique em **Deploy**.

## Observação
O conteúdo de estudo do aplicativo foi estruturado a partir do ebook fornecido. Os recursos de marca-texto, anotações e progresso usam armazenamento local do navegador.
